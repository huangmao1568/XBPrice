# 2026-10-03 数据库页CSV导出功能

## 需求
数据库页（DatabasePage）的「月均汇总」和「原始数据」两个视图都要能导出 CSV。
**最终方案（经用户两次反馈调整）**：
1. 不要单独的「导出目录」按钮，改为点击导出按钮时直接弹出资源管理器的
   「另存为」对话框，让用户自选文件名与保存位置；
2. 不要「导出月均CSV」「导出原始CSV」两个按钮，合并为一个「导出」按钮，
   按当前所在视图自动导出对应内容。

## 改动文件

### 新增 CsvExporter.cs
CSV 导出辅助类，纯静态方法、无 WinUI 依赖，可单独链接测试。
- `Escape(string)`：含逗号/引号/换行时加双引号并翻倍内部引号
- `Number(double, int)`：用 InvariantCulture 输出纯数字（不带千分位，Excel 才能当数字算）
- `BuildBytes/WriteTo`：写入 UTF-8 BOM（Excel 双击打开不乱码的必要条件）
- `BuildMonthlyCsv / BuildRawCsv`：两种表格的 CSV 生成，字段顺序与界面表头一致
- `BuildFileName(prefix, filterParts)`：前缀_筛选描述_时间戳.csv，
  作为「另存为」对话框的默认文件名

> 注：初版曾实现「导出目录记忆」（导出目录.txt + LoadExportFolder/SaveExportFolder），
> 按用户要求已整体删除，不需要再实现类似需求。

### UiModels.cs
- `MonthlyRow` 补 `MinPrice / AvgPrice / MaxPrice` 三个 double 字段
- `RawRow` 补 `Price` double 字段
- 原因：原界面只绑定 `AvgPriceText`/`PriceText`（带千分位的字符串），
  写进 CSV 会被 Excel 当成文本而无法参与计算。

### DatabasePage.xaml
顶部工具栏刷新按钮左侧新增一个按钮：`导出`(E9D5)

### DatabasePage.xaml.cs
- `UpdateExportButtons()`：当前视图有数据才允许导出（在 Reload / ReloadRaw 末尾调用）
- `ExportButton_Click()`：单方法按 `_summaryMode` 分派
  —— 汇总视图导月均、原始视图导原始报价；文件名前缀随之切换（月均价 / 原始报价），
  导出的内容永远与屏幕所见一致
- `PickSaveFileAsync(prefix)`：FileSavePicker 弹「另存为」，
  默认文件名带筛选描述+时间戳；用 InitializeWithWindow 指定 HWND
- `DescribeFilters()`：收集非「全部」的筛选维度拼文件名

## 关键决策
- **单按钮按视图分派**：导出内容与屏幕所见一致，用户无需先想「我导的是哪个」；
  比两个按钮更省界面空间（用户明确要求从两个合并为一个）
- **用 FileSavePicker 而非 FolderPicker**：用户要的是弹资源管理器自选位置，
  「另存为」本身就是资源管理器对话框，且能同时定文件名和目录，一举两得
- **直接用 System.IO 写文件**而非 StorageFile：路径来自 Picker 已有权限，
  省去 StorageFile 那套异步包装
